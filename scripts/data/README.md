# Profile source data

Download the pinned Garmin `Profile.xlsx` here, then run `scripts/parse_profile.py`
with the matching `--version`. The workbook and legacy CSV exports are ignored;
no CSV conversion, version.txt, or manual edits to message numbers are needed.

See [the generator instructions](../README.md) for commands and verification.
Source provenance is tracked in `fittie/profile/source.json`.
